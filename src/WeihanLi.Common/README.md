# WeihanLi.Common

## Intro

`WeihanLi.Common` is a common library based on .NETStandard2.0.

Low-dependency, AOT-compatible extensions and primitives now live in `WeihanLi.Core`. `WeihanLi.Common` references `WeihanLi.Core` and keeps the heavier DI, AOP, logging, data access, HTTP, JSON, and configuration integrations.

## Features

- Dependence Injection
- Fluent Aspects -- AOP implement
- Event Related(EventBus/EventQueue/EventStore)
- Logging Framework
- Dapper-like Ado.Net extensions
- TOTP implement
- and more ...
